## Independent Resource searches

Apps can use `BatchSearchResourceReferences` to request independent searches together. Check each result status and install the matching Core and App runtime before use. Existing individual searches remain available. See the [Resource Reference guide](https://developers.nexia.to/docs/platform-extensions-resource-references).
