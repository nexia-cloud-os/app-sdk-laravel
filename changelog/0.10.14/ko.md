PHP SDK 0.10.14에 읽기 전용 JSON GET 처리기용 `BatchableRead` 메서드 속성이 추가되었습니다. Core 0.8.161과 Manager alpha.85 지원을 적용한 뒤 일반 개발 업데이트 또는 빌드·배포 절차로 App 카탈로그를 다시 생성하세요. 기존에 속성을 선언하지 않은 처리기도 계속 지원합니다.
