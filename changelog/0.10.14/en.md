PHP SDK 0.10.14 adds the optional `BatchableRead` method attribute for read-only JSON GET handlers. Adopt Core 0.8.161 and Manager alpha.85 support, then regenerate the App catalog through the normal development update or build/deployment flow. Existing unannotated handlers remain supported.
